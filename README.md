# Ibrohimjon Resume Workspace

Vite + React + TypeScript resume project with ATS-optimized content and modern dark portfolio styling.

## Run
1. `npm install`
2. `npm run dev`

## Deliverables
- One-page ATS resume: `docs/resume-one-page.md`
- Extended resume: `docs/resume-extended.md`
- GitHub profile README: `docs/github-profile-readme.md`
- Titles, headline, bio, summary, grouped skills: `docs/professional-positioning-pack.md`

## UI Source
- App: `src/App.tsx`
- Styling: `src/styles.css`
